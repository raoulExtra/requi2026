# Requi

## Scope

Requi is a project requirements and architecture knowledge graph for the OMA workspace.

## Description

Semantic project data is stored in `requi.db`. Terms and scopes are rendered directly from SQLite into HTML; layers, requirements, and Wikidata Lexemes also retain generated Markdown projections. Terms can belong to multiple scopes, and scope pages group related terms and requirement categories. The result is a clickable HTML site.

See [_HOME.md](_HOME.md) for the repository layout and workflow.
