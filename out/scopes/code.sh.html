./requi.sh command reference

./requi.sh add

Create a term, layer, or scope using the compact command


./requi.sh add ENTITY NAME [--definition TEXT] [--layer ID] [--scope ID]

Arguments:

  • entity (enum, required) — term, layer, or scope
  • name (string, required) — Entity name; remaining words are accepted for term names
  • --definition (string, optional) — Term definition
  • --layer (layer-id, optional) — Layer ID
  • --scope (scope-id, optional) — Scope ID; repeat for multiple scopes

./requi.sh add-scope

Create a scope in SQLite and render its HTML page


./requi.sh add-scope NAME [--description TEXT]

Arguments:

  • name (string, required) — Scope name
  • --description (string, optional) — Scope description

./requi.sh add-term

Create a term in SQLite and render its HTML page


./requi.sh add-term NAME --definition TEXT [--layer ID] [--scope ID]

Arguments:

  • name (string, required) — Display name
  • --definition (string, required) — One-line definition
  • --layer (layer-id, optional) — Layer ID, for example data
  • --scope (scope-id, optional) — Scope ID; repeat for multiple scopes

./requi.sh ast

Inspect command structure or emit parser-construction code


./requi.sh ast [COMMAND] [--format FORMAT]

Arguments:

  • name (command, optional) — Command name; omit for all commands
  • --format (enum, optional) — tree, json, or python
